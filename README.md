# ระบบตรวจใบหน้า LIVE · โรงเรียนบ้านนาดอย

หน้าเปิดกล้อง LIVE สำหรับเชื่อมต่อกับระบบบันทึกการมาเรียนของโรงเรียน

- เว็บไซต์: https://patop1241-hub.github.io/school-face-scanner/
- Repository: https://github.com/patop1241-hub/school-face-scanner
- ใช้กล้องผ่าน HTTPS และประมวลผลใบหน้าในเบราว์เซอร์ของเครื่องครู
- เปิด URL จริงใน popup หลังครูยืนยันแล้ว ไม่เปิดหน้าต่าง about:blank มาบังกล่องยืนยัน
- ก่อนเปิดกล้องจะแสดงปุ่ม “อนุญาตและเปิดกล้อง” ให้ครูกดเอง แล้วจึงเรียกคำขอสิทธิ์ของ Chrome/Edge
- เมื่อจับคู่ใบหน้าได้จะอ่านชื่อและ “มาเรียน” ด้วย SpeechSynthesis โดยเคารพตัวเลือกแจ้งชื่อด้วยเสียงจากหน้าระบบหลัก
- รูปอ้างอิงรับจากระบบหลักผ่าน postMessage และเปรียบเทียบภายในเบราว์เซอร์
- วิดีโอจากกล้องไม่ถูกอัปโหลดหรือจัดเก็บโดย GitHub Pages

## ข้อควรทราบเรื่องเสียง
การอ่านชื่อใช้เสียงภาษาไทยที่ติดตั้ง/ให้บริการโดยเบราว์เซอร์และระบบปฏิบัติการ หากไม่มีเสียงภาษาไทยหรือปิดเสียงอุปกรณ์ ระบบอาจอ่านไม่ได้หรืออ่านด้วยเสียงเริ่มต้นของอุปกรณ์

## ความปลอดภัย
ระบบนี้ยังไม่มีการตรวจจับการปลอมแปลงใบหน้า (liveness / anti-spoof) ครูต้องตรวจทานรายชื่อก่อนบันทึกทุกครั้ง และควรได้รับอนุญาต/ความยินยอมที่จำเป็นก่อนใช้รูปนักเรียน
